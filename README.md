## 🚀 Featured Project

### Globix — E-commerce & Social Marketplace

A real-world cross-platform marketplace combining e-commerce, social networking, payment processing, logistics, and digital analytics.

**Key features and technical contributions:**

- Full Stack development of mobile and web applications.
- Custom REST APIs and PostgreSQL database management.
- Multi-vendor marketplace architecture.
- Integration of Stripe, PayPal, Mercado Pago, Sistecrédito, and cash-on-delivery payments.
- Automated order creation and management.
- Shipping and logistics integration through Skydropx.
- Seller subscriptions and webhook-based payment confirmation.
- Social features including videos, comments, and reactions.
- Multilingual and multicurrency functionality.
- AWS cloud infrastructure and Docker containerization.
- Push notifications and geolocation services.
- Digital analytics and conversion tracking.
- Production deployment, maintenance, and continuous improvement.
